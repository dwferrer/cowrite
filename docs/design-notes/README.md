# Design-exploration archive

Raw material from the multi-agent design exploration that produced the numbered docs in
`docs/`. Kept for provenance only — **where anything here contradicts `docs/NN-*.md`, the
numbered doc wins.**

Process: six subsystem proposals were drafted in parallel (`<subsystem>.md`), each adversarially
critiqued (`<subsystem>-critique.md`), then cross-checked in a coherence review
(`coherence.md`, findings F1–F24). `RESOLUTIONS.md` is the binding decisions register that
reconciled them; the final docs were revised under it and swept by two verification passes
(`verify-consistency.md`, `verify-brief.md`).
